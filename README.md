# Lifer bird stickers

Bird stickers used by [Lifer!](https://lifermap.com), keyed by eBird species code.

**Stickers: [huashu-bird-sticker](https://github.com/alchaincyf/huashu-bird-sticker) by Huashu, CC BY 4.0.**
These files are copies of that library: the full-quality originals, plus smaller copies trimmed to the bird.
They are AI-generated illustrations, not field-guide plates; see the original repository for how they were
made, reviewed and credited, and to report a mistake.

| Path | What |
|---|---|
| `s/<ebird-code>.webp` | Trimmed to the bird, 256 px on the long side |
| `full/<ebird-code>.webp` | The original file, unchanged |
| `index.json` | Every code that has a sticker, with the small copy's width and height |
